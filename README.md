# Análisis Exploratorio de Datos: Estadísticas de Pokémon

Bienvenido a mi primer proyecto de portafolio

## Objetivo del Proyecto
En este proyecto analicé una base de datos real de 800 Pokémon para descubrir patrones en sus estadísticas de combate usando programación y consultas a bases de datos.

## Herramientas Utilizadas
Para este análisis, construí una tubería de datos utilizando las siguientes tecnologías:
* **Python (Pandas):** Para la extracción y lectura de datos desde internet.
* **SQL (SQLite3):** Para crear una base de datos virtual, filtrar información y realizar agrupaciones.
* **Seaborn & Matplotlib:** Para la visualización de datos.

## Descubrimientos Clave

Durante mi análisis exploratorio, respondí a las siguientes preguntas:

**1. ¿El mito de los Legendarios es real?**

Es real, ya que si se encontró una relación entre que los Pokémon legendarios tienen unas estadisticas base más altas que los comunes

**2. ¿Quiénes son los "Tanques" del juego?**
Utilizando consultas SQL, descubrí que los Pokémon con más de 150 Puntos de Vida (HP) son principalmente de tipo normal como Chansey, Snorlax y Wobbuffet.

**3. ¿Qué tipo de Pokémon tiene más vida en promedio?**
Agrupando los datos con SQL, comprobé matemáticamente que el tipo Dragón es el rey indiscutible de la resistencia en el juego.

## 🚀 Conclusión
Este proyecto me permitió experimentar la lectura y limpieza de un CSV alojado en la nube, hasta la consulta estructurada en bases de datos para encontrar la respuesta a las preguntas planteadas.
